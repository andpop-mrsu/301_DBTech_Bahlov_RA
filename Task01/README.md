# Task01 — Описание структуры данных

## Назначение

Каталог содержит исходные данные и результаты их первичной обработки
в рамках задания Task01.

## Структура файлов

| Файл                | Описание                                                      |
|---------------------|---------------------------------------------------------------|
| `ratings.csv`       | Оценки фильмов пользователями                                 |
| `ratings_count.txt` | Минимальный и максимальный `userId` и количество строк с ними |
| `sqlite.txt`        | Версия SQLite и режимы вывода утилиты `sqlite3`               |
| `README.md`         | Описание структуры файлов (этот файл)                         |

## Описание ratings.csv

| Столбец     | Тип     | Описание                             |
|-------------|---------|--------------------------------------|
| `userId`    | integer | Идентификатор пользователя           |
| `movieId`   | integer | Идентификатор фильма                 |
| `rating`    | float   | Оценка (0.5 – 5.0)                   |
| `timestamp` | integer | Время выставления оценки (Unix time) |
